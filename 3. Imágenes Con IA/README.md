## 🔬 3. Relación con el trabajo técnico

Las imágenes representan conceptos desarrollados en el informe:

| Elemento | Función |
|---|---|

| Fibra óptica | Transporta información mediante pulsos de luz. |
| Electrodos | Generan el arco eléctrico para realizar la fusión. |
| Manga termocontraíble | Protege la unión después del empalme. |
| Medición en dB | Permite evaluar la pérdida óptica estimada. |
